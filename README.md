# মিনি ইনভেস্ট (mini-invest)

একটি সহজ স্ট্যাটিক ডেমো ওয়েবসাইট — ইনভেস্টমেন্ট ক্যালকুলেটর এবং ক্লায়েন্ট-সাইড পোর্টফোলিও ম্যানেজার (localStorage)।

ফাইলসমূহ:
- `index.html` — মূল পেজ
- `styles.css` — স্টাইল
- `script.js` — জাভাস্ক্রিপ্ট লজিক

চালানোর উপায়:
1. এই রিপোজিটরি ক্লোন করো বা ডাউনলোড করো
2. ফাইলগুলো একই ফোল্ডারে রেখে `index.html` ব্রাউজারে ওপেন করো

প্রয়োজন হলে আমি GitHub Pages চালু করে সরাসরি হোস্ট করে দিতে পারি।
